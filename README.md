# CAREER COMPASS - 働き方適性診断 Webアプリケーション（サーバーレス静的版）

就職・転職に悩むすべてのビジネスパーソンに向けた、深層心理にアプローチする働き方適性診断ポータル。  
Python等のバックエンドサーバーを必要とせず、Vercel、Cloudflare Pages、GitHub Pagesなどの無料静的ホスティング基盤上で**24時間365日・完全無料**で稼働します。

---

## 🌟 特徴
1. **完全サーバーレス・静的動作**:
   - 設問データ・全タイプ図鑑・診断アルゴリズム（5問クイック＆30問精密）・4桁暗号コード生成のすべてがブラウザ内で高速完結。
2. **公式LINE連携（暗号コードゲート）**:
   - 30問回答後に直接結果を表示せず、「AI活用コーディネーター｜あおやま」公式LINEへの誘導と4桁暗号コードを発行。
3. **URLパラメータによる直接ルーティング**:
   - `?code=1001` 等のアクセスで該当する深層心理診断結果ページ（レーダーチャート含む）を直接呼び出し可能。
4. **ゼロコスト運用**:
   - Vercel または Cloudflare Pages の無料枠（Freeプラン）で無期限・常時高速配信可能。

---

## 🚀 デプロイ手順（Vercel）
1. 本フォルダ（またはリポジトリ）をGitHubへプッシュします。
2. [Vercel](https://vercel.com/) にログインし、「Add New...」➔「Project」を選択します。
3. GitHubリポジトリをインポートし、Framework Presetは「Other」のまま「Deploy」をクリックします。
4. 約10秒〜20秒で全世界へ公開される専用URL（`https://xxx.vercel.app`）が自動発行されます。
